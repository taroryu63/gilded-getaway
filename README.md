Gilded Getaway is a top-down heist game. Cross the vault floors as the thief, stay out of the guards' vision cones and the sweeping security cameras, grab every piece of loot — coins, bars and the Aurelïon Sapphire — and reach the getaway before the three-stage alarm maxes out. Three floors, smoke pellets to break line of sight, and sound generated entirely in code with WebAudio — no external assets, no libraries.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a desktop browser
```
